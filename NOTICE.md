# Notices

The methods are written from the published formulas (Chernozhukov, Demirer, Duflo and Fernandez-Val, 2018) and checked against the R package `GenericML` (GPL-3), which is not included.
The learners use the R packages `glmnet` (GPL-2 | GPL-3) and `ranger` (GPL-3), which are bundled with the module when it is built.
The sample data are simulated.
